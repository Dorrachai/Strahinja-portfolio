# Remix of Dark Creative Portfolio template

🟦 PROMPT PARA LOVABLE — SITE DE PORTFÓLIO (ESTILO ECHELON® + DANIEL TRIENDL)

Quero que você crie um site de portfólio minimalista, sofisticado e visualmente impactante, seguindo rigorosamente as referências visuais enviadas nas imagens anexas (Echelon® template e portfólio do Daniel Triendl).

Abaixo estão todas as diretrizes de design, layout, tipografia, paleta, estrutura, e conteúdo que você deve seguir.

🎨 1. Direção Visual / Design System

Basear exatamente nas referências do Echelon® + Daniel Triendl:

Paleta de Cores

Fundo principal: branco puro (#FFFFFF)

Texto: preto puro (#000000)

Cinzas sutis para separadores e micro-interações (#EAEAEA, #BEBEBE)

Evitar degradês ou cores saturadas no UI — o destaque deve vir das imagens dos projetos.

Pequenos acentos podem usar um cinza quente ou off-black, se necessário.

Tipografia

Replicar o estilo das referências:

Títulos grandes em fonte serifada forte (estilo editorial, como Georgia / Inter Tight serif / Lora Bold ou equivalente).

Subtítulos e labels em fonte sans geométrica moderna (Inter, Söhne, Helvetica Now — Lovable pode escolher proximidade).

Tamanho grande de títulos, ocupando respiro generoso.

Kerning amplo e impacto visual.

Grid e Layout

Muito whitespace.

Margens laterais amplas (mínimo 64px).

Galeria em mosaico similar ao Daniel Triendl:

imagens grandes, responsivas, bem espaçadas

grid assimétrico, artístico

Home hero minimalista com texto grande centralizado e imagens distribuídas ao redor (como nas referências).

Transições suaves entre páginas.

Estética geral

Editorial

Contemporâneo

Gráfico e limpo

Foco total nas imagens

Interações sutis (hover fade-in, movimento leve)

🖼️ 3. Imagens

Use placeholders agora.
O usuário enviará depois as imagens reais — então o site deve estar preparado para substituição fácil.

🎯 4. Requisitos funcionais

Totalmente responsivo (mobile deve manter o look editorial).

Animações de hover fluídas.

Scroll sutil e elegante.

Header fixo pequeno e minimalista.

Não usar cores chamativas no UI — tudo deve ser silencioso e elegante.
